# Coordinator Overview override

The Overview is an institution operations cockpit. Use one dark contextual
hero for orientation, a four-card snapshot for quick scanning, a bordered
attention queue for decisions, and two monitoring sections below. Cards are
reserved for distinct metrics; actions and exceptions use list rows so the page
does not become a wall of cards.

Use the existing MentorMAMA navy/teal tokens rather than introducing the
generated green palette. Keep the hero restrained, use amber/red only for
attention semantics, and use Lucide outline icons at a consistent size.
Primary action: review placements. Secondary action: manage cohorts.
Responsive order: hero, snapshot cards (one column at 375px, two columns from
sm, four from xl), attention queue, then monitoring sections. No information
depends on hover and all controls retain 44px minimum height.
