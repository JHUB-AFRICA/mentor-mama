# Document design system (PDF, print, spreadsheet exports)

Every document MentorMAMA produces (server PDFs, browser print sheets, XLSX exports) follows this page. It applies
the Brand Guidelines (§05 logo usage, §06 colour, §07 type, §09 "structured layer") to paper. If this page and the
guidelines disagree, the guidelines win.

## Principles

1. **Foundation, then structure.** White canvas, navy text, generous margins. Data uses a strict grid: one table style,
   one KPI style, one chart palette. No decorative colour.
2. **Navy and white dominate (~80%). Teal is the accent (~15%).** Teal is for the rule under the header, KPI values,
   chart bars and the active/positive state. Terracotta (`#D97757`) only marks something that needs attention (open
   concerns, overdue). Never full-bleed colour bands.
3. **Master logo files only.** The header uses `logo-horizontal-accent.svg` ("MAMA" in Guiding Teal, the approved UI
   treatment). Never re-set "MentorMAMA" as live text and never use a letter "M" as a stand-in. Minimum mark size
   10mm in print; keep clear space equal to the learner circle (0.293 × mark height).
4. **Watermark = the monochrome lockup** (`logo-horizontal-mono.svg`, per guidelines §04 "Monochrome — single-colour
   print, watermarks"), Midnight Navy at **5% opacity**, centred on the page, **never rotated** (§05: don't rotate or
   flip the mark), about 55% of the page width, behind all content, on every page.
5. **Say what it is, who it is for, and how to handle it.** Every document has a title, a scope line, the generated
   time with timezone, a confidentiality notice and "Page X of Y".

## Type

| Level     | Face                 | Size (pt) | Use                     |
| --------- | -------------------- | --------- | ----------------------- |
| Title     | Manrope Bold         | 22        | Document title          |
| Section   | Manrope SemiBold     | 12        | Section headings        |
| KPI value | Manrope Bold         | 18        | Numbers in KPI tiles    |
| Body      | Inter Regular        | 8.5–9.5   | Table cells, paragraphs |
| Label     | Inter SemiBold, caps | 6.5–7     | Table headers, eyebrows |
| Caption   | Inter Medium         | 7–7.5     | Footer, metadata        |

Fonts are bundled in `backend/apps/core/documents/assets/fonts` (SIL OFL 1.1; Manrope static instances generated from
the Google Fonts variable font with fontTools). The portal print sheets use the same families through
`@fontsource`.

## Page layout (A4)

- Reports with wide tables: A4 landscape, margins 16mm top/bottom header and footer bands, 14mm sides.
- Records (one person, one checklist): A4 portrait.
- **Header (every page):** logo lockup left (height 10mm, the print minimum), document title + scope right in Navy muted; a 0.6pt
  Stone rule below with a 28mm Teal segment at the left.
- **Footer (every page):** confidentiality notice left, "Generated 11 Nov 2026, 14:02 EAT" centre-right,
  "Page 2 of 5" right, Inter Medium 7pt Navy muted.
- **Cover block (first page only):** eyebrow (caps label, Teal), title, one-line description, then a meta row
  (scope, period, generated by role) and the KPI strip.

## Components

- **KPI strip:** equal tiles on Mist, 3mm radius, label above value; value in Manrope Bold Teal (Terracotta when it
  flags attention and is > 0).
- **Charts:** inline SVG. Horizontal bar list for stages; donut for a share split, with a legend table beside it. No
  3D, no gradients, no shadows, no chart borders.
- **Table:** header row Navy with white caps labels, repeated on every page; zebra Mist rows; 0.4pt Stone row
  dividers; rows never split across pages; numbers right-aligned with tabular figures.
- **Status pill:** rounded, 6.5pt Inter SemiBold. Active/arranged = Teal on Teal light; completed = Success tint;
  attention = Terracotta tint; neutral = Navy muted on Mist.
- **Empty state:** a single calm sentence in the table area, never an empty grid.

## Spreadsheets (XLSX)

- Sheet 1 "Report": a title row (Manrope-like bold), a scope/generated row, a blank row, then the data with a Navy
  header row (white bold), frozen header, auto-filter, readable column widths, human column labels, dates as real
  dates, booleans as Yes/No.
- Sheet 2 "About": what the export contains, what it never contains, handling notice, generated time.
- CSV and JSON stay machine-readable (raw keys, raw values, original column order) for integrations. The XLSX is the
  human report: readable labels, labelled stages, real dates, Yes/No and percentages. Integrations must use CSV or
  JSON, not XLSX (decision 2026-11-11).
- PDF is for reading. Exports above 1,500 rows are refused as PDF (`pdf_too_large`) and should use Excel.

## Security

The PDF renderer only loads files from `backend/apps/core/documents/assets` and `data:` URLs; every other URL is
refused. All values pass through Django template autoescaping.
